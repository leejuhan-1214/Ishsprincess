# RE:ACTION · 인천과학고 연애실험

이름을 직접 입력하고 시작하는 한국어 브라우저 비주얼노벨. 인천과학고등학교 **1학년 1반**에 편입한 주인공이 여섯 반 친구와 인천 사이언스 페어를 준비하며, 대화 선택과 방과 후 만남으로 관계를 바꿔 간다.

**GitHub Pages 배포 대상:** [게임 플레이 주소](https://leejuhan-1214.github.io/Ishsprincess/)

위 주소는 이 저장소의 공개 게임 주소로 사용하는 경로다. 실제 서비스 여부는 저장소의 Pages 배포 결과에 따라 결정된다. 저장소의 `.git` 주소는 게임을 플레이하는 주소가 아니라 소스를 복제하는 주소다.

등장인물·사건·교내 시설 배치는 허구다. 실제 학교 운영, 학생, 행사, 건물을 재현한 작품이 아니다.

## 시작과 플레이

새 게임의 이름 입력란에는 기본 이름이 없다. 이름을 입력해야 시작할 수 있으며 앞뒤 공백은 제거한다. 이름은 1~12자로, 첫 글자는 문자 또는 숫자여야 한다. 이후에는 문자·숫자·공백·마침표·가운뎃점·밑줄·하이픈을 사용할 수 있다. 입력한 이름은 대사 속 `{name}` 위치에 표시된다.

공통 장면을 읽고 선택지를 고른 뒤 지도에서 방과 후 만남을 선택한다. 자유 행동은 한 번의 지도 구간마다 3회까지이며, 같은 인물은 그 구간에서 한 번만 만날 수 있다. 인물 위치는 챕터·시간대·회차 시드에 따라 바뀌므로 매일 같은 장소에 서 있지 않는다. 지도 구간을 마치면 다음 주요 날짜로 이동한다. D-64부터 매일을 전부 시뮬레이션하는 방식이 아니라 중요한 날짜를 따라가는 구성이다.

방과 후 만남은 장소에 맞는 3라운드 미니게임으로 시작한다. 댄스실은 리듬과 안전, 화학실은 실험 절차, 밴드실은 사운드 체크, 천문대는 관측, 미술·미디어실은 창작 권리, 컴퓨터실은 파일 복구·보안 문제를 다룬다. 활동 점수는 호감도·신뢰도·전용 수치와 페어 완성도에 반영된다.

방과 후 대화는 화면에 표시되는 다섯 개의 상황별 선택지로 진행한다. 방과 후 선택지는 공통적인 ‘경청·약속·무시’ 문장을 반복하지 않는다. 인물별 6개 고유 사건과 12개 행동 덱을 조합해 원테이크 녹음, 블랭크 대조, 블라인드 검증, 거울 없는 안무, 레이더 겹치기, 삼색 팔레트처럼 그 인물과 현재 문제에서만 성립하는 행동을 제시한다. 같은 인물을 12번 만나도 같은 선택 문장이 다시 표시되지 않으며, 선택 버튼의 태그로 행동 성격을 구분한다.

만남의 사건과 선택지는 캐릭터·장소·방문 회차에 맞춰 구성된다. 선택에 따라 호감도·신뢰도 등이 변하고, 관계와 이전 이벤트 기록에 따라 돌발 이벤트가 열린다.

호감도·신뢰도·질투도·전용 수치가 기준을 넘거나 회차별 확률을 만족하면 돌발 이벤트가 열린다. 친밀한 둘만의 시간, 처음 맡기는 부탁, 질투, 경계 확인, 일정 취소 등의 사건은 인물별로 한 번씩 발생하며 관계 수치에 따라 우선순위가 달라진다. 돌발 이벤트는 3비트 단편 컷신으로 시작한다. 여섯 인물 모두 대표 우연 이벤트에 전용 일러스트가 사용된다: 세계의 밴드실 정전, 준연의 안전 트레이 안 비커 균열, 현솔의 실험실 정전, 태우의 댄스 연습 사고, 태훈의 갑작스러운 소나기, 서율의 기울어진 캔버스다.

선택에는 호감 증가뿐 아니라 신뢰 하락, 질투 증가, 공동 작업과 안전의 손실도 있다. 공통 루트가 끝나면 호감도 50·신뢰도 40 이상인 인물 중 합산 수치가 높은 최대 두 명의 개인 루트가 열린다. 한 사람을 선택하거나 혼자 돌아갈 수 있으며, 별도 조건을 충족하면 히든 다자 루트가 제시된다.

### 조작과 화면 기능

| 조작 | 동작 |
| --- | --- |
| 대사창 클릭·탭, `Space`, `Enter` | 현재 문장을 즉시 표시하거나 다음 대사로 진행 |
| 선택지 클릭·탭, 숫자 `1`~`6` | 화면에 열린 선택지 결정 |
| 지도 위치 선택 → 인물 선택 | 장소별 미니게임과 인물 대화를 진행하고 행동 1회 사용 |
| `Esc` | 메뉴 열기·닫기 |
| `Ctrl` 누르기 | 이미 읽은 대사만 빠르게 넘기기 |
| 대화 도구의 `자동` | 선택지에서 멈추는 자동 진행 |
| 대화 도구의 `기록` | 최근 대화와 선택 기록 보기 |
| `관계` / `관계 수첩` | 개인 수치와 학급 공통 수치 확인 |

자동 저장 1개와 수동 저장 10개를 제공한다. 이미 사용한 수동 슬롯은 한 번 더 눌러 덮어쓰기를 확인한다. 제목 화면의 `이어서 하기`에서 자동·수동 기록을 불러올 수 있다.

설정에서 대사 표시 속도, 음량, 배경음 사용, 선택 후 수치 변화 표시를 조정한다. 수치 표시를 켜면 선택 결과 중 앞쪽 최대 네 항목을 알림으로 보여 준다. 전체 효과는 관계 수첩에서 확인할 수 있다. 배경음은 처음에는 꺼져 있으며 브라우저에서 사용자가 켜야 재생한다. 전체화면 버튼은 브라우저가 지원하는 경우 사용할 수 있다.

`기억의 서랍`에는 34개 엔딩의 해금 기록과 힌트, 제작한 배경 여섯 장·인물별 돌발 이벤트 일러스트 여섯 장·인물 시트가 있다. 모든 엔딩은 배경 이동, 인물 등장, 장면 문장, 엔딩 타이틀이 순서대로 이어지는 고유 컷신으로 시작하며 엔딩 화면이나 기억의 서랍에서 다시 볼 수 있다. 컷신은 일시정지·건너뛰기를 지원한다. 돌발 이벤트 일러스트와 컷신도 풍경과 인물 탭에서 다시 볼 수 있다. 엔딩을 한 번 이상 본 뒤 새 게임을 시작하면 자동으로 New Game+ 회차가 된다. 이름은 새로 입력하며, 기존 읽은 대사와 엔딩 수집 기록을 이어서 사용한다. 모바일에서는 화면 버튼으로 조작할 수 있다.

대사 수는 모든 분기의 합계이며 한 번의 플레이 분량이 아니다. 대사 사이에 자동으로 덧붙이던 분위기 묘사·감정 해설을 제거하고 원본 사건과 대화, 장면별 추가 선택지를 유지했다. 방과 후 조합 대화와 엔딩 본문은 위 2,936줄 집계에 포함하지 않았다. 기존 저장 기록은 불러올 때 대사 위치를 보정한다.

개인 수치는 호감도·신뢰도·질투도·전용 수치이며, 공통 수치는 1반 조화도·페어 완성도·교내 평판·연구 윤리·안전이다. 모든 수치는 0~100으로 제한한다. 교내 평판도 음수가 되지 않는다. 수치는 게임의 분기 장치이며 인물의 현실적인 심리 상태를 측정하는 척도가 아니다.

## 로컬 실행

Node.js 22 이상과 pnpm 또는 npm을 준비한다. 저장소에는 `pnpm-lock.yaml`을 사용한다.

```bash
git clone https://github.com/leejuhan-1214/Ishsprincess.git
cd Ishsprincess
pnpm install --frozen-lockfile
pnpm dev
```

npm을 사용할 경우 다음 명령으로 설치한다. `package-lock.json`이 없는 첫 설치에는 `npm ci` 대신 `npm install`을 사용한다.

```bash
npm install
npm run dev
```

개발 서버가 터미널에 표시하는 주소를 브라우저에서 연다. 프로젝트 파일을 `file://`로 직접 열어서 실행하지 않는다. 실행 중에는 외부 게임 서버나 API 키가 필요하지 않다.

```bash
# 검사
pnpm test
# 또는 npm test

# TypeScript 검사 및 배포용 빌드
pnpm build
# 또는 npm run build

# 빌드 결과 로컬 미리보기
pnpm preview
# 또는 npm run preview
```

## GitHub Pages 배포 구조

`vite.config.ts`는 상대 경로 `base: './'`와 출력 폴더 `docs`를 사용한다. `docs/`는 Markdown 설명 폴더가 아니라 **빌드된 게임**이다. `main` 브랜치의 `/docs`를 Pages 소스로 지정하는 구성이다.

1. 코드를 수정하고 테스트와 빌드를 실행한다.
2. 변경된 소스와 `docs/` 빌드 결과를 함께 커밋하고 `main`에 반영한다.
3. 저장소 Settings → Pages에서 `Deploy from a branch`, 브랜치 `main`, 폴더 `/docs`를 선택한다.
4. Pages 배포 작업이 성공한 뒤 위 플레이 주소에서 확인한다.

소스만 바꾸고 `docs/`를 다시 빌드하지 않으면 공개 게임은 이전 내용으로 남는다. 다음 빌드에서 출력 폴더가 다시 생성되므로 `docs/`를 직접 편집하지 않는다. 저장소 이름이나 호스팅 주소를 바꾸면 이 문서의 플레이 주소도 함께 수정한다.

## 저장 데이터

진행 상태는 브라우저의 `localStorage`에 저장한다. 서버 계정이나 클라우드 동기화는 없다. 다른 브라우저, 다른 기기, 개발 서버와 공개 사이트는 저장 공간이 서로 다르다. 브라우저 사이트 데이터를 지우면 세이브와 수집 기록도 지워진다.

저장 키 접두사는 `reaction-v1:`이다. 세이브는 `reaction-v1:save:<slot>` 형태이며, 엔딩·읽은 대사·히든 루트 판정 기록은 `reaction-v1:meta`에 저장된다. 읽은 대사 키에는 장면과 선택 반응이 포함되어 다른 선택의 반응을 같은 문장으로 취급하지 않는다.

세이브는 주인공 이름, 진행 단계, 수치, 플래그, 자유 행동, 대화 기록과 회차 시드를 포함한다. 이름과 수치 등 주요 구조를 확인한 저장 데이터만 불러온다. 대화 기록은 최근 800줄까지 유지한다.

원본 대사는 화면 컴포넌트와 분리한 데이터다. `Scene.lines`는 핵심 사건의 대사 배열이며 `storyDirector.ts`가 실행 시 두 개의 추가 선택지를 조합한다. 방과 후 대화는 `characterAI.ts`가 캐릭터·장소·방문 회차와 이벤트 기록을 바탕으로 구성한다. 새로운 장면을 추가하면 루트 배열과 진행 조건을 함께 확인한다. 주인공 이름을 고정해서 쓰지 말고 `{name}`을 사용한다. 새 엔딩 ID를 반환하도록 바꿨다면 `endings.ts`에도 같은 ID를 등록한다.

이미지 제작 출처, 배경·인물 교체 방법과 음악 수정 방법은 [ASSETS.md](ASSETS.md)에 정리했다.

### 개인 엔딩

각 인물에게 TRUE 1개, GOOD 1개, BAD 2개가 있다. 일반 TRUE 조건은 호감도 80 이상, 신뢰도 75 이상, 질투도 35 이하, 해당 인물의 핵심 선택 표식 3개 이상, 연구 윤리 50 이상, 안전 40 이상이다. 여기에 전용 수치 조건이 붙는다.

- 전세계 집착 60 이하
- 방준연 위축 40 이하
- 최현솔 짜증 55 이하
- 김태우 경쟁심 60 이하
- 고태훈 감성 동조·이서율 영감은 60 이상

GOOD은 특수 BAD에 해당하지 않으면서 호감도 65·신뢰도 50 이상일 때다. 특수 BAD와 신뢰도 부족은 TRUE·GOOD보다 먼저 판정한다. 정확한 우선순위는 `resolveEnding()`을 따른다.

| 인물 | TRUE | GOOD | BAD 1 | BAD 2 |
| --- | --- | --- | --- | --- |
| 전세계 | 카메라 밖의 전세계 | 앵콜 뒤의 고백 | 완벽한 타임라인 | 읽음 1 |
| 방준연 | 자신의 이름으로 | 늦게 도착한 답장 | 네가 없으면 못 해 | 깨진 비커 |
| 최현솔 | 오차를 인정하는 법 | 한쪽 이어폰 | 정답만 남은 관계 | 무음 방송 |
| 김태우 | 결승선 다음에도 | 다음 무대의 약속 | 마지막 카운트 | 센터 자리 |
| 고태훈 | 별과 문장 사이 | 비가 그친 뒤 | 흐린 예보 | 지워진 문장 |
| 이서율 | 미완성의 초상 | 첫 번째 관람객 | 복제된 색 | 빈 프레임 |

공통 엔딩은 `증명되지 않은 가설`, `실험실 출입 금지`, `조작된 결과`, `아무도 기다리지 않는 방과 후`, `1반 냉전`, `완성되지 않은 부스`다. 다자 엔딩은 `다중성의 해답`, `아직 결론 내리지 않은 가설`, `일곱 방향의 침묵`, `한 사람만 남은 단체 채팅`이다.

### 히든 루트 자격

여섯 명 모두 호감도 60 이상·신뢰도 70 이상·질투도 30 이하이며, 각 인물을 지도에서 한 번 이상 만나야 한다. 추가로 조화도 80 이상, 페어 완성도 85 이상, 연구 윤리 70 이상, 세계 집착 60 이하, 준연 위축 50 이하, 현솔 짜증 60 이하가 필요하다. `exclusive:`로 시작하는 독점 약속 표식이 있으면 제외한다.

자격을 만족할 때만 확률을 계산한다. 기본 확률은 15%이며 다음을 더하고 뺀다.

- 기록된 공동 성공 표식당 +5%p, 이 항목 최대 +30%p
- 조화도 90 이상 +10%p
- 여섯 명 신뢰도 모두 80 이상 +10%p
- New Game+ 회차 +15%p
- 질투도 25 이상인 인물당 −5%p
- 기록된 비밀 약속 표식당 −10%p
- 자격 충족 후 이전 확률 실패가 1회이면 +20%p

통상 최종 확률은 5~75%다. 자격을 충족한 확률 판정에서 누적 두 번 실패한 상태라면 다음 자격 충족 판정은 100%다. 자격 미달은 0%다. 세이브에 저장된 시드를 사용하는 `seededRoll()`로 판정하며 같은 회차의 같은 판정을 다시 불러와도 새 난수를 뽑지 않는다.

히든 TRUE는 각 인물의 신뢰도 85 이상·질투도 20 이하, 세계 집착 45 이하, 히든 핵심 표식 4개 이상을 기준으로 한다. 이 기준은 평균값이 아니라 **모든 인물이 각각 충족**해야 하는 조건이다. 세계 집착과 관계 갈등에 따른 특수 BAD가 우선할 수 있으며, 연애 관계를 보류하는 선택도 별도로 반영한다. 수치와 플래그 조건을 수정할 때는 `haremEligible()`, `haremChance()`, `resolveEnding()`을 함께 점검한다.
